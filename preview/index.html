ThoughtLite 排版

正文用衬线体，行高 1.75，纸面是奶油色 #fdfcf6，墨色是 #2a2a28。链接不靠颜色区分，靠静息下划线。

为什么是这套结构

上游只有一个强调色：文字本身的颜色。所以整套皮肤是单色的，语义状态色保留 GitHub Alert 的四种色相。
  • heading 用 4px / 2px 的横线收口
  • 引用是 4px 的 --shadow-color 竖条
  • 表格用 booktabs 式三条横线
令牌LightDark
canvas#fdfcf6#0e0e0c
ink#2a2a28#dddddb
block#f0ede0#1e1d17
tokens.ts复制
// 令牌覆盖层
export const skin = {
  canvas: "#fffffd",
  ink: "#2a2a28",
  overrideTokens(id, tokens)
}
